# Expense Tracker

A simple Python-based expense tracking application that allows users to record,
view, and analyze their daily expenses.

## Features

- Add new expenses
- Store expenses in a CSV file
- View saved expenses
- Calculate total expenses
- View category-wise spending
- Visualize expenses using a bar chart
- Input validation for invalid amounts

## Technologies Used

- Python
- CSV
- Pandas - No
- Matplotlib
